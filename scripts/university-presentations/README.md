# Private university presentation production

The reconciled copy and contact input are private operator files, never source-controlled. Existing UG/KNUST presentations are visual/function references and must not be regenerated by this workflow.

1. Parse/reconcile the supplied eight-slide copy and contact provenance privately. Keep all 39 records `awaiting_user_approval` / `unsent`; uncertain names use an office salutation. Preserve contact UUIDs and existing link tokens.
2. Inside Artifact Session, call `authorDeck(presentation, record)` from `author.mjs` for each new institution. Render at 2880×1620 (1280×720 at scale 2.25), using embedded Carlito and DejaVu Serif fonts matching the approved UG reference. Export native, eight-page vector PDFs; add links at the documented `LINKS` rectangles. The recurring footer is unlinked.
3. Reuse the existing image pipeline, with a **private** output directory:

   `node scripts/prepare-sdsn-slides.mjs /private/input/institution institution-id --ug --output-dir /private/output/institution`

   This produces the unchanged 1280/1920/2880 WebP sizes at quality 90, without upscaling. Do not put unapproved decks in `public/`.
4. Validate all slide copy, image sizes/order, eight PDF pages, embedded fonts and four hyperlink annotations; inspect rendered slides and the viewer at desktop/mobile sizes.
5. `node --import tsx scripts/university-presentations/build-review.ts /private/reconciled.json /private/review-output` produces 39 unsent drafts and the private contact matrix. It cannot send or schedule mail.
6. **Only after explicit approval of the private Firebase payload/destination**, run `import.ts` with `--conditions=react-server --import tsx`, the reconciled JSON and private asset directory. It checks that anonymous reads are denied, refuses production and already-contacted/sent records, deduplicates bounded assets by SHA-256, and updates only existing unsent preview contacts. Do not deploy Firestore rules or change access settings from this utility.

`proposalOutreachPresentations` and `proposalOutreachAssets` are private presentation storage, not a second event ledger. Analytics continue through the existing `proposalOutreachEvents`, ingestion API, owner dashboard and generic MCP response. SDSN/UG/KNUST event names and configuration remain unchanged.

The capability-gated viewer, image and PDF routes fail closed in production. Revoked, expired, wrong-institution or wrong-recipient links cannot load the new presentation. No release or sending command is provided.
