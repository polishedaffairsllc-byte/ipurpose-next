## Non-AI loops / request multiplication

- `app/context/AuthContext.tsx` is mounted by `app/layout.tsx`. Its fallback declares five polls at three-second intervals, but setting `polling` false while `timedOut` remains true re-enters the effect and starts again. A positive `adminInitialized` response reloads the page, resetting in-memory attempt state. Persistent auth initialization failure can therefore cause recurring status requests/reloads, asset transfer and analytics reinitialization. **Medium**, approximately 20 status requests/minute per stuck tab before reload effects; needs lifecycle tests and a persisted/bounded retry policy (0.5–1 day). Deferred from this backend-only PR; review before launch, contain through Vercel controls. `/api/admin/status` itself does not read Firestore.
- Public `/api/affirmation/today` reads the entire ordered affirmation collection and filters active entries in memory. Public feedback/welcome-popup endpoints also accept database writes without a shared limiter. **Medium**, repeated traffic multiplies document reads/writes and retained data; bounded queries, carefully keyed caching for non-personalized affirmations, and shared admission controls need follow-up (0.5–1 day). No cache is added in this PR.
- Public `/api/health` writes Firestore once and calls OpenAI Models once per probe. It has no auth/rate/cache guard. **Medium**, one million probes means one million writes plus compute; edge-throttle to **6/min/IP**, monitor aggregate, and separately consider a cached readiness check (0.5 day). It does not incur generation-token charges.
- `lib/gptClient.ts` loops over an existing stream until `done`; this is not repeated generation. Raw `/api/ai/stream` mock-response interval emits a finite number of words; cancellation cleanup is incomplete but performs no paid calls. Streaming disconnects elsewhere can leave provider work unaccounted; see limiter deferral.
- Analytics initialization retries only when another event requests it, not on a timer. GA/Meta server fetches are one-shot but unbounded in duration. Stripe redeliveries and scheduled email overlaps can multiply their calls.
- UI loading guards, debounced journal/blueprint/starter saves, and bounded list queries reduce ordinary duplicate work. They are not authentication, distributed throttling, or an aggregate dollar budget.

Non-AI daily/monthly dollar ceilings cannot be derived from this repository: no complete deployed SKU/region/plan/rules/traffic configuration exists here. Track operations and bytes (e.g. requests × documents/read, emails/submission, uploads × bytes, egress/download) and price them against actual provider accounts. Do not treat the OpenAI estimate as the total launch bill.
